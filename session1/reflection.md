# Practical 1 - Reflection



## Q1. How does Git commit history help maintain a software project?



Git commit history helps us see all the changes made to a project. Each commit saves the changes with a message. If something goes wrong, we can check the history to find which change caused the problem. For example, my commit history shows when I added the README, `.gitignore`, Session 1 notes, and evidence screenshots.



## Q2. What is the difference between Git and GitHub?



Git is a tool used to save and track changes in our project. GitHub is a website where we can store our Git projects online. Git helps us manage files and commits on our computer, while GitHub helps us share our work with others. In this practical, I used Git to manage my files and GitHub to upload and share my repository.



## Q3. What risk is reduced by using branches and pull requests instead of making changes directly to the main branch?



Branches allow us to make changes without affecting the main project. We can test our changes first before adding them to the main branch. A pull request allows other people to check our work and give feedback. This helps reduce mistakes and prevents unfinished changes from affecting the main project.



## Q4. Which Git commands work locally, and which interact with GitHub?



Some Git commands are used on our own computer. Examples are `git add`, `git commit`, `git status`, `git diff`, and `git log`. Other commands are used to connect with GitHub, such as `git clone`, `git push`, and `git pull`. In this practical, I used `git push` to upload my work to GitHub and `git pull` to get the teammate's changes.



## Git Concepts Table

|Concept|Simple Explanation|
|-|-|
|Repository|A folder that contains project files and their history.|
|Working Tree|The files that we can see and edit.|
|Staging Area|A place where we select changes before saving them in a commit.|
|Commit|A saved record of changes made to the project.|
|Branch|A separate place to work on changes without affecting the main branch.|
|Merge|Combining changes from one branch into another branch.|
|Remote|An online copy of our repository, such as on GitHub.|
|Push|Sending our local commits to GitHub.|
|Pull|Getting the latest changes from GitHub to our computer.|
|Clone|Making a local copy of a repository from GitHub.|
